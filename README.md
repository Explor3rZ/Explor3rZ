## 🚀 Sobre mim

**Felipe**, aqui — desenvolvedor web júnior em busca de uma oportunidade na área de programação.

Venho de uma trajetória em **suporte de TI em uma organização militar**, o que me deu disciplina, responsabilidade e uma boa base em infraestrutura e resolução de problemas.

Gosto de construir aplicações web completas com **React, Node.js e Express**, cuidando tanto da experiência de quem usa quanto da segurança e organização do que roda por trás.

Atualmente, estou:

- 🔨 Evoluindo meus projetos full stack e meu portfólio
- 📚 Aprofundando autenticação, boas práticas de API e arquitetura limpa
- 🐧 Praticando administração de sistemas **Linux**

Meu objetivo é simples: escrever código limpo, entregar software confiável e crescer como desenvolvedor criando coisas que fazem diferença.
